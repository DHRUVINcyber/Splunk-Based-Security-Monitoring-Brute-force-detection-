# 📊 Splunk-Based Security Monitoring (SIEM)

## 📌 Overview
A centralized SIEM monitoring system built on **Splunk** for real-time 
data collection, threat detection, alerting, and visualization across 
IT infrastructure.

## 🛠️ Tools & Technologies
- Splunk Enterprise (Forwarders, Indexers, Search Heads)
- Splunk SPL (Search Processing Language)
- Splunk MLTK (Machine Learning Toolkit)
- Role-Based Access Control (RBAC)
- Slack & Email Alerting Integration

## 🎯 Key Features
- Real-time log ingestion from servers, apps & network devices
- Custom SPL dashboards for CPU, memory, error rates
- Threshold-based alerts for failed logins & anomalies
- Brute-force attack detection via SIEM correlation
- Predictive analytics using MLTK

## 🚀 Architecture
Data Sources → Universal Forwarders → Indexers → Search Head → Dashboard
